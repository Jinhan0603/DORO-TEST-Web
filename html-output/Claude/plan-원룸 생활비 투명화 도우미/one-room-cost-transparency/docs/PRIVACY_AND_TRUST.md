# 개인정보·신뢰 설계

## 1. 개인정보 최소 수집

v0.1에서는 다음 정보를 수집하지 않습니다.

- 주민등록번호
- 실명
- 상세주소
- 계약서 원본
- 고지서 원본 이미지
- 계좌번호
- 임대인 개인정보

입력 정보는 다음 수준으로 제한합니다.

- 방 이름 또는 별칭
- 구 단위 지역
- 보증금, 월세, 관리비
- 공과금 추정액
- 관리비 포함 항목
- 계약 전 확인 여부

## 2. 로컬 우선

- 모든 상태는 브라우저 `localStorage`에 저장합니다.
- 서버 전송은 없습니다.
- 초기화 버튼으로 데이터를 삭제할 수 있습니다.

## 3. 신뢰 문구 원칙

계산값은 확정값처럼 표현하지 않습니다.

권장 문구:

- 참고 추정입니다.
- 계약서와 공식 고지서 기준으로 다시 확인하세요.
- 추가 확인이 필요합니다.
- 계약서에 명확히 적는 것이 안전합니다.

금지 문구:

- 정확한 공과금입니다.
- 100% 돌려받습니다.
- 사기입니다.
- 절대 계약하지 마세요.
- 확정 반환액입니다.

## 4. 법률·분쟁 리스크

이 서비스는 임대차 법률 판단이나 분쟁 대리 서비스가 아닙니다.

화면 하단 또는 상세 카드에 다음 안내를 유지합니다.

> 이 결과는 사용자가 입력한 정보와 시제품 계산 규칙을 바탕으로 한 참고용 추정입니다. 실제 관리비, 공과금, 보증금 정산, 계약 조건은 계약서와 공식 고지서, 임대인·중개사 확인 내용에 따라 달라질 수 있습니다.

## 5. 실제 서비스화 전 검토 항목

- 개인정보 처리방침
- 서비스 이용약관
- 법률 자문 면책 고지
- 고지서 OCR 처리 시 이미지 보관 여부
- 계약서 분석 시 민감정보 마스킹
- 공공데이터 이용 약관
- API 호출 로그와 사용자 식별정보 분리
