# 출처·검증 메모

이 문서는 시제품 확장 시 참고할 공개 출처와 검증 포인트를 정리합니다.

## 관리비 투명화

- 국토교통부는 원룸·오피스텔 등 소규모 주택의 관리비 투명화를 위해 온라인 중개플랫폼 관리비 세부내역 표시, 계약 전 관리비 명확화, 임대차계약서 비목별 금액 명시 등을 추진했습니다.
- 원룸·오피스텔 등 소규모 주택 관리비 세부내역 표시 의무화가 2023년 9월 21일부터 시행됐습니다.

## 공동주택 관리비 공개

- K-apt 공동주택관리정보시스템은 공동주택 관리비 공개 정보를 제공합니다.
- 다만 원룸, 다가구, 소규모 오피스텔은 사용자가 직접 비교·해석해야 하는 영역이 남습니다.

## 전기요금

- 한국전력 전기요금계산기는 주택용 저압·고압 등 계약종별 요금 계산을 지원합니다.
- v0.1에서는 정확한 전기요금 산정이 아니라 계절별 비용 흔들림을 보여주는 참고 시뮬레이션만 제공합니다.

## 실제 서비스화 시 주의

- 공공요금 공식 요금표는 개정될 수 있으므로 최신 자료 확인이 필요합니다.
- 관리비·퇴실 정산은 계약서와 고지서 기준으로 다를 수 있습니다.
- 법률 판단, 분쟁 조정, 확정 환급액 산정처럼 보이는 표현은 피해야 합니다.
