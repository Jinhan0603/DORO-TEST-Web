# 디자인 가이드

## 1. 디자인 키워드

| 키워드 | 설명 |
|---|---|
| 투명함 | 월세 외 숨은 비용이 한눈에 보여야 함 |
| 현실적 | 실제 계좌에서 나가는 돈 기준으로 설명 |
| 안심 | 계약 전 불안을 줄이고 질문을 돕는 톤 |
| 경고 | 위험 요소는 명확하지만 단정하지 않음 |
| 가벼움 | 사회초년생도 부담 없이 입력 가능 |

| 상태 | 색상 | 문구 |

| 명확 | Green | 확인됨, 명확해요 |

## 6. 주요 컴포넌트

### RealMonthlyCostCard

사용자가 첫 화면에서 서비스 가치를 느끼는 카드입니다.

표시 항목:

- 평상시 진짜 월 주거비
- 광고 월세와의 차이
- 여름 예상
- 겨울 예상
- 참고 추정 안내

### MaintenanceBreakdownCard

관리비를 포함/미포함/확인 필요로 나눕니다.

예시:

```text
관리비 80,000원
포함: 인터넷, 수도, 공용전기
미포함: 전기, 가스
확인 필요: 퇴실 청소비
```

### UtilitySeasonSimulator

계절별 공과금 변동을 보여줍니다.

- 평상시
- 여름
- 겨울
- 월별 비용 파도 그래프

### ContractQuestionList

계약 전 질문을 체크리스트로 보여주고 복사할 수 있게 합니다.

### MoveOutSettlementCard

보증금 반환 예상과 차감 가능 항목을 보여줍니다.

## 7. UX 문구 원칙

### 좋은 문구

- 월세 외에 실제로 나갈 비용을 합산했어요.
- 관리비에 포함된 항목을 계약 전에 확인하세요.
- 이 항목은 추가 확인이 필요해요.
- 겨울에는 난방비 때문에 비용이 늘 수 있어요.
- 월세보다 총액 기준으로 비교하는 것이 안전해요.
- 계약서에 적힌 차감 항목인지 확인하세요.

### 피해야 할 문구

- 사기입니다
- 절대 계약하지 마세요
- 100% 돌려받습니다
- 임대인이 잘못했습니다
- 정확한 공과금입니다
- 확정 반환액입니다
