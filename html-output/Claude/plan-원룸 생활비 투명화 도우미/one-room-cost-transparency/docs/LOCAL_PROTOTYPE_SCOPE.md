# 로컬 시제품 범위

## 구현됨

- localStorage 기반 방 후보 상태 저장
- 진짜 월 주거비 계산
- 계절별 비용 시뮬레이션
- 관리비 포함/미포함/확인 필요 표시
- 비용 투명도 점수
- 위험 신호 카드
- 방 후보 비교표
- 계약 전 질문 체크리스트
- 질문 복사
- 퇴실 정산 예상
- 최근 월별 고지서 목업 표시
- zero-dependency dev/build/lint/test 스크립트

## 의도적으로 제외됨

- 실제 부동산 매물 API
- 실제 공공요금 API
- 실제 한전 요금 산정
- 실제 K-apt 데이터 호출
- OCR 고지서 업로드
- 계약서 법률 판단
- 전자서명/계약 기능
- 서버 저장
- 결제 연동

## 이유

초기 MVP의 목적은 정확한 행정·요금 처리보다 **사용자가 비용 구조를 이해하고, 계약 전 질문을 할 수 있는지**를 검증하는 것입니다.

## v1 후보

- 온보딩 플로우 분리
- 방 후보 CRUD
- 월별 고지서 기록 CRUD
- PDF/Markdown 리포트
- OCR 목업
- 공식 계산기 링크 연결
- 프리미엄 3,900원 Paywall UI
