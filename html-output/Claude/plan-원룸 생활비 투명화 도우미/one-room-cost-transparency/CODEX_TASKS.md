## Phase 1 — 고객이 처음 이해하는 순간 만들기

### 1-1. 4단계 온보딩 분리

현재 홈 우측 빠른 입력 패널을 별도 온보딩 플로우로 분리합니다.

단계:

1. 방 기본 정보: 이름, 지역, 주거유형, 평수
2. 월세·보증금·관리비: 보증금, 월세, 관리비, 정액/실비/모름
3. 관리비 포함 항목: 인터넷, 수도, 공용전기, 청소비, 엘리베이터, 주차 등
4. 공과금·난방: 전기, 가스, 수도 납부 방식과 계절별 추정

완료 기준:

- [ ] 첫 진입 시 온보딩 CTA가 보임
- [ ] 단계별 진행률 표시
- [ ] 입력 완료 시 홈 대시보드로 이동
- [ ] localStorage에 저장
- [ ] `npm run check` 통과

### 1-2. 진짜 월세 게이지 고도화

광고 월세와 실제 월 주거비 차이를 더 강하게 보여줍니다.

완료 기준:

- [ ] 광고 월세 vs 평상시 총액 비교
- [ ] 여름/겨울 최대 부담액 표시
- [ ] 보증금 기회비용 포함 여부 토글
- [ ] 참고 추정 안내 문구 유지

### 1-3. 관리비 포함 항목 편집 UI

완료 기준:

- [ ] 포함/미포함/확인 필요 상태를 칩으로 변경 가능

- [ ] 관리비 세부항목 계약서 기재 체크와 연결
