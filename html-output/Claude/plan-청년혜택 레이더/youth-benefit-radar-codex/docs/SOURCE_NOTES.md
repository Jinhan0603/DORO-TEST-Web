# 출처·검증 메모

이 저장소는 정책 데이터의 정확성보다 UI/UX 시제품 검증을 우선하는 로컬 목업입니다. 실제 서비스화 전에는 아래 출처의 최신 정보를 기준으로 정책 데이터와 문구를 재검수해야 합니다.

## Codex CLI

- OpenAI Help Center의 Codex CLI 시작 안내는 전역 npm 설치 명령 `npm install -g @openai/codex`를 안내한다.
- Codex CLI는 로컬 터미널에서 파일을 읽고, 수정하고, 명령을 실행할 수 있는 코딩 에이전트로 설명된다.
- 승인 모드는 Suggest, Auto Edit, Full Auto로 나뉘며, 로컬 프로젝트에서 작업할 때 승인 수준을 선택할 수 있다.
- 별도 문서에서는 `codex --login` 후 ChatGPT 계정으로 로그인하는 흐름을 안내한다.

## 온통청년

- 온통청년은 청년정책 및 청년공간 정보를 제공하는 공식 청년정책 포털이다.
- OPEN API는 회원가입, 인증키 신청, 담당자 승인 절차를 거쳐 사용할 수 있다.
- v0.1에서는 실제 호출하지 않고, `src/data/policies.js`의 목업 정책 데이터로 UI와 매칭 로직을 먼저 검증한다.

## 정부24 / 보조금24

- 정부24 보조금24는 나의 혜택, 간편 찾기, 전체 혜택 탐색 기능을 제공한다.
- 청년혜택 레이더는 공식 포털을 대체하지 않고, 사용자의 조건 해석과 마감/서류 실행을 보조하는 서비스로 설계한다.

## 정책금융상품

- 청년도약계좌 등 정책형 금융상품은 가입 권유가 아니라 조건 이해 보조로 표시해야 한다.
- 실제 가입 가능 여부, 납입 조건, 정부기여금, 중도해지 조건은 공식 금융기관 안내에서 최종 확인해야 한다.
