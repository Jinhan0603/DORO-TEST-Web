# 개인정보·신뢰 설계

## 기본 원칙

청년혜택 레이더는 민감한 생활정보를 다루므로, 초기 시제품부터 개인정보 최소 수집과 오인 방지 문구를 UI에 반영한다.

## 수집하지 않는 정보

- 주민등록번호
- 생년월일 원문
- 상세 주소
- 회사명
- 실제 증빙서류 파일
- 계좌번호
- 건강보험료 원문

## 수집하는 정보

- 만 나이
- 시/도, 시/군/구
- 연소득 구간
- 재직/구직/프리랜서 등 상태
- 주거 상태
- 관심 분야
- 생애 이벤트

## 사용자 안내 문구

```text
이 결과는 사용자가 입력한 조건과 정책 정보를 기준으로 한 사전 매칭입니다.
실제 신청 가능 여부와 지원금 지급 여부는 담당 기관의 심사 결과에 따라 달라질 수 있습니다.
신청 전 공식 공고를 반드시 확인하세요.
```

## 금융상품 오인 방지

청년도약계좌, 청년희망적금, 전월세 대출 등 금융성 상품은 아래 배지를 표시한다.

```text
정책금융 · 가입 권유 아님 · 공식 안내 확인 필요
```

## 운영 리스크

| 리스크 | 대응 |
|---|---|
| 잘못된 자격 판정 | “신청 가능성” 표현, 공식 확인 안내 |
| 마감일 오류 | 마지막 확인일 표시 |
| 정책 변경 | 변경 뱃지, 갱신일 표시 |
| 금융상품 추천 오인 | 가입 권유 아님 표시 |
| 개인정보 부담 | 범위형 입력과 로컬 저장 |
