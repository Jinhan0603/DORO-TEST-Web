# 청년혜택 레이더 제품 사양서 v0.1

## 1. 제품 정의

청년혜택 레이더는 사용자의 조건을 입력받아 현재 신청 가능성이 높은 청년정책·지원금·저축상품·주거지원을 보여주고, 마감일과 제출서류를 관리하는 웹서비스다.

## 2. 핵심 고객

- 26~33세
- 첫 직장 1~3년차
- 연 3,000만~5,000만 원 구간
- 자취 중 또는 독립 예정
- 평일에 정책 탐색에 시간을 쓰고 싶지 않은 사람
- “나한테 되는 것만” 알고 싶은 사람

## 3. 핵심 문제

| 문제 | 제품 대응 |
|---|---|
| 정책을 찾기 어렵다 | 조건 기반 매칭 |
| 조건 해석이 어렵다 | 쉬운 문장 변환 |
| 마감을 놓친다 | D-day 캘린더 |
| 서류를 몰라서 늦어진다 | 제출서류 체크리스트 |
| 공식 포털이 복잡하다 | 가능성 높은 3개 우선 노출 |

## 4. MVP 기능

### P1
- 개인 조건 입력
- 혜택 매칭 결과
- 마감 캘린더
- 제출서류 체크리스트
- 정책 상세 조건 해석

### P2
- 생애 이벤트 기반 추천
- 신청 진행 상태
- 정책 변경 요약

### P3
- 월 3,900원 프리미엄 화면
- 무제한 매칭
- 마감 리마인더
- 문서 체크

## 5. 성공 기준

- 3분 안에 조건 입력 완료
- 입력 후 즉시 첫 매칭 결과 제공
- 10초 안에 “지금 신청 가능성이 높은 혜택” 이해
- 첫 이용 중 서류 체크리스트 1회 이상 사용
- 월 3,900원 결제 이유가 “마감 알림 + 서류 체크”로 설명됨

## 6. UX 카피 원칙

좋은 문구:
- “입력 조건 기준으로 신청 가능성이 높은 혜택을 찾았어요.”
- “정확한 신청 전 공식 공고 확인이 필요해요.”
- “마감이 가까워요. 서류부터 확인하세요.”

피해야 할 문구:
- “100% 신청 가능”
- “지원금 수령 확정”
- “무조건 받을 수 있음”
- “이 금융상품에 가입하세요”
