# 로컬 시제품 범위

## 포함

- 순수 HTML/CSS/JS 기반 UI
- 목업 정책 데이터
- 규칙 기반 매칭 점수 계산
- 홈 대시보드
- 혜택 매칭 결과
- 정책 상세 조건 해석
- 마감 타임라인
- 제출서류 체크리스트
- localStorage 기반 프로필 저장

## 제외

- 실제 온통청년 API 연동
- 정부24 로그인 또는 인증
- 실제 알림 발송
- 결제 연동
- 주민등록번호/증빙서류 업로드
- 금융상품 가입 유도
- 최종 자격 판정

## 개발자 참고

v0.1은 “서비스가 유용해 보이는가”를 검증하기 위한 시각적 시제품이다. 따라서 정확한 정책 DB 구축보다 아래 경험을 우선한다.

1. 조건을 입력했더니 추천 혜택이 줄어든다.
2. 추천 이유와 확인할 조건이 보인다.
3. 마감일이 보인다.
4. 필요한 서류가 보인다.
5. 프리미엄 3,900원의 이유가 보인다.
