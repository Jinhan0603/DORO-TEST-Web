# AGENTS.md — Codex 작업 원칙

이 저장소는 **청년혜택 레이더**의 로컬 UI/UX 시제품입니다. Codex CLI는 아래 원칙을 우선합니다.

## 제품 목적
- 사용자가 나이·소득구간·거주지·직장상태·주거상태를 입력하면 목업 정책 DB에서 신청 가능성이 높은 청년혜택을 보여준다.
- 공식 판정 서비스가 아니라 **사전 매칭/체크리스트 도구**다.
- UI 문구에서 “100% 가능”, “확정 수령”, “무조건 신청 가능” 같은 표현을 쓰지 않는다.

## 개발 원칙
- 현재는 외부 API를 호출하지 않는다.
- 사용자 정보는 `localStorage`에만 저장한다.
- 주민등록번호, 상세주소, 회사명, 실제 증빙서류 파일 업로드 기능을 만들지 않는다.
- 목업 데이터는 `src/data/policies.js`에 둔다.
- 정책 조건 판별 로직은 `src/features/matching.js`에 둔다.
- UI는 사용자가 10초 안에 “내가 뭘 신청해야 하는지” 이해하도록 만든다.

## 기술 원칙
- 이 프로젝트는 **zero-dependency static prototype**이다.
- `npm install` 없이도 `npm run dev` 또는 `python3 -m http.server 5173`로 실행 가능해야 한다.
- 새 라이브러리를 추가하기 전, 반드시 순수 HTML/CSS/JS로 가능한지 먼저 판단한다.
- 외부 패키지를 추가할 경우 README와 package.json, 빌드 스크립트를 함께 갱신한다.

## 우선순위
1. 조건 입력 온보딩
2. 혜택 매칭 카드
3. 정책 상세 조건 해석
4. 마감 D-day 및 캘린더
5. 서류 체크리스트
6. 신청 진행 상태
7. 프리미엄 3,900원 가치 검증 화면

## 검증 명령
작업 후 아래 명령을 실행한다.

```bash
npm run lint
npm run build
```

## 금지사항
- 금융상품을 직접 추천하거나 가입을 유도하는 문구를 추가하지 않는다.
- 실제 정책명처럼 보이는 데이터를 추가할 때는 “목업” 또는 “공식 확인 필요” 문구를 함께 둔다.
- 정부/지자체 최종 심사를 대체하는 것처럼 보이는 UI를 만들지 않는다.
